# 人生模拟器 · Life Simulator

一个纯静态、无构建依赖的人生模拟器网页应用。从出生到终老，体验一场又随机又精彩的人生。

## 玩法

- **开局设定**：姓名、性别、家庭背景（贫寒 / 普通 / 富裕）
- **天赋点分配**：智力、情商、体质、颜值，共 12 点自由分配
- **逐年推进**：每一年可能触发随机人生事件，你需要在不同选择间权衡
- **六维属性**：智力 / 情商 / 体质 / 颜值 / 财富 / 幸福
- **人生结算**：根据寿命与综合属性给出专属结局评价

## 事件库

内置数十个覆盖幼儿期 / 童年 / 少年 / 青年 / 成年 / 中年 / 中老年的随机事件，
每个事件都提供多个带属性后果的选择分支，让每次游戏都不重样。

## 技术栈

- HTML / CSS / JavaScript（原生，无构建、无框架）
- 响应式设计，适配手机与桌面
- 无外部运行时依赖（仅字体走 Google Fonts CDN）

## 快速开始

直接用浏览器打开 `index.html` 即可运行。也可用任意静态服务器：

```
npx serve .
```

## 部署

本项目为纯静态站点，可直接部署到 Vercel 或 GitHub Pages。

## 文件结构

```
index.html      页面入口
style.css       样式
data.js         数据层（属性、事件库、结局）
app.js          游戏逻辑与渲染
```
